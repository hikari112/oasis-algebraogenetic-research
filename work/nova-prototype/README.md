# NOVA finite-probe prototype

NOVA stands for **Non-Sofic Observable Valuation Architecture**.

This prototype tests the finite computational shell around the proposed object. It does **not** claim to implement or verify a non-sofic group; every finite action is the wrong place to prove that property.

## What it implements

- a primitive distribution-state interface separated from its numerical representation;
- adaptive Cantor-cylinder refinement;
- a Dirichlet-smoothed Bayesian posterior predictive distribution;
- an exact, replayable symbolic split program;
- finite probes and process observability signatures;
- a deliberate decorative hidden process that the probes correctly flag as observationally inert;
- a non-factorized target distribution with prefix, parity, and long-range dependencies;
- an independent-Bernoulli baseline.

## Research claim tested

Increasing the number of cylinder leaves should improve external approximation of a structured distribution, while symbolic process replay remains exact. A process invisible to every selected probe is flagged as decorative and cannot count toward the strong non-sofic-essentiality claim.

## Theoretical engine boundary

The full architecture replaces the prototype process set with a faithful symbolic action of a validated non-sofic group. It must not compile that group into finite permutations. Instead it symbolically composes processes and evaluates only the finite probes requested by a task.
