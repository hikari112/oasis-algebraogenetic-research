# Constructive snapshot: a non-sofic orbit architecture

Status: pre-literature constructive freeze. This document defines the object before naming or novelty classification.

## 1. Typed primitive object

The architecture begins with four roles rather than identifying a distribution with a numerical measure.

- `D`: distributional states, treated as primitive objects.
- `P`: composable processes acting on states.
- `E`: probes/effects that expose a finite observation of a state.
- `V`: valuations that turn probe responses into numbers, probabilities, or losses.

A measure, vector, density, log-potential, sample stream, or tensor is a representation of a distributional state, not its definition.

## 2. Core object

A **Non-Sofic Observable Universal Orbit Approximator** (NOUOA) is a tuple

`A = (D, Gamma, action, d0, E, V, T, Realize)`

with these properties.

1. `Gamma` is a countable non-sofic group of processes.
2. `action : Gamma -> Aut(D)` is faithful.
3. `d0 in D` is a cyclic seed state.
4. `E` is a separating family of finite probes on the closure of the orbit `Gamma.d0`.
5. `Realize` maps probed/valued orbit states into a target space `T`.
6. External universality holds:

   `closure { Realize(g.d0) : g in Gamma } = T`.

7. Orbit observability holds: for every distinct `g,h in Gamma`, some continuation `k in Gamma` and probe `e in E` distinguishes `kg.d0` from `kh.d0` after valuation.
8. Non-soficity is essential: there is no sofic quotient `q : Gamma -> Q` through which the observed universal orbit factors.

Properties 7-8 exclude the trivial construction `Gamma = N x H` in which a non-sofic factor `N` is present but ignored by a conventional universal approximator `H`.

## 3. Two realizations

### 3.1 Literature-backed Hilbert realization

For a countably infinite non-sofic group `N`, the Glasner-Weiss universal hypercyclic representation supplies a faithful bounded linear representation

`S : N -> GL(H)`

on a separable Hilbert space. Every free ergodic probability-preserving `N`-action is isomorphic to `(H, nu, S)` for a suitable full-support invariant distribution `nu`.

This is externally universal for `N`-dynamical distributions and internally non-sofic. Whether it satisfies the stronger orbit-observability and essentiality clauses for an AI readout must be proved for the chosen readout.

### 3.2 Constructive Cantor realization

Let `N` be countably infinite and non-sofic, `K = {0,1}^N`, and let `A` be the additive group of rational-valued locally constant cylinder functions on `K`. The Bernoulli shift lets `N` act on `A`; form

`Gamma = A semidirect N`.

It acts affinely on `C(K,R)` by

`(a,n).f = a + n.f`.

The action is faithful, `Gamma` is non-sofic because it contains `N`, and the orbit of zero is `A`, which is uniformly dense in `C(K,R)`. A Gibbs readout

`P_a(dx) proportional to exp(a(x)) P_0(dx)`

is weakly dense in probability laws on Cantor space when `P_0` has full support.

This proves external universality, but essentiality remains open: the dense orbit of zero is generated by `A`, so the non-sofic `N` may reorganize the basis without being necessary for density. This is a candidate, not the final novel object.

## 4. Architectural principle

The internal process engine is never approximated by a finite permutation latent. It remains an exact symbolic process algebra. Computation exposes only finite probes of its action.

`input -> process-word policy -> exact symbolic executor -> primitive distribution state -> finite probes -> valuation -> prediction`

Only the external probe responses are approximated or optimized. Algebraic relations are enforced by the symbolic executor, not learned as soft penalties.

## 5. Prototype claim

The prototype will not claim to instantiate or verify non-soficity. No finite experiment can do that. It will test the architecture around that invariant:

- exact symbolic process composition;
- finite cylinder probes;
- increasing external approximation power with probe depth;
- Bayesian/Gibbs distribution readout;
- separation between primitive state, representation, probe, and valuation;
- an observability test that catches decorative process factors.

## 6. Novelty gates

The final object is novel only if the literature audit does not already combine all of:

1. a faithful non-sofic process group;
2. a universal or dense external realization;
3. finite probe-based computation without finite approximation of the engine;
4. Bayesian/distributional readout;
5. a proof that the non-sofic part is essential to universality or observable composition.

Failure of gate 5 leaves a useful architecture but not the strong object proposed here.
