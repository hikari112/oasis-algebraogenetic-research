# Algebraogenetic path space: topology before probability

## Result

The proposed object now has a precise executable instance:

\[
\mathfrak X_{\mathrm{alg}}
=\left(
\mathcal B_{\mathrm{cert}}(G,\mathbb Z),
\tau_{\mathrm{cyl}},
G\curvearrowright\mathcal B_{\mathrm{cert}}
\right),
\]

with transformation groupoid

\[
G\ltimes\mathcal B_{\mathrm{cert}}
\]

and algebraic crossed product

\[
\mathcal B_{\mathrm{cert}}(G,\mathbb Z)\rtimes G.
\]

Here:

- \(G\) is the theorem-backed exact non-sofic group used by OASIS;
- \(\mathcal B_{\mathrm{cert}}\) is the semantic quotient of certified-total
  bounded integer-valued programs on \(G\) by extensional equality; its
  representatives are effective, although equality of arbitrary representatives
  is not decidable;
- \(\tau_{\mathrm{cyl}}\) is the topology generated by agreement on finitely
  many exact continuations; and
- \(G\) acts by exact left translation,
  \(\alpha_g(p)(x)=p(g^{-1}x)\).

No probability distribution is required to define this object. A probability,
positive functional, or Bayesian state can be added later as a valuation on its
observable algebra.

## The algebraogenetic path-space theorem

The constructed object has all three properties conjectured in the discussion.

> **Theorem.** The algebraogenetic path space has computable local
> continuation, contains non-finitely-isolated semantic states, and its action
> on the countable semantic-program set is non-sofic in the sense of Gao,
> Kunnawalkam Elayavalli, and Patchell.

The three clauses have separate proofs.

### 1. Computable local continuation

Every native semantic representative is a certified-total program. For every
finite exact continuation \(x\in G\), evaluation \(p(x)\) terminates. Program
addition, multiplication, translation, exact group multiplication, and exact
group inversion are computable on representatives.

The action law is

\[
\alpha_g\alpha_h=\alpha_{gh},
\]

because

\[
\alpha_g(\alpha_h(p))(x)
=p(h^{-1}g^{-1}x)
=p((gh)^{-1}x).
\]

The runtime checked this law on thirteen exact group continuations.

### 2. Non-finitely-isolated semantic states

For a finite continuation set \(F\subset G\), let

\[
U_F(p)
=\left\{
q:\forall x\in F,\ q(x)=p(x)
\right\}
\]

be the cylinder neighborhood of \(p\).

For each counter machine \(M\), recall the bounded clock

\[
\operatorname{clock}_M(x)
=1
\quad\Longleftrightarrow\quad
M\text{ halts within }c(x)\text{ steps},
\]

where \(c(x)\) is native exact complexity. Every evaluation is bounded and
terminates.

Given any finite \(F\), choose a machine that halts after more than
\(\max_{x\in F}c(x)\) steps. Its clock agrees exactly with zero on all of \(F\),
but it is semantically nonzero because \(G\) is infinite and exact canonical
complexity is unbounded. Therefore

\[
\forall F\text{ finite},\qquad
U_F(0)\setminus\{0\}\neq\varnothing.
\]

Zero is not isolated by any finite continuation observer.

The executable sequence used continuation-cylinder depths \(4,8,12\). It
constructed nonzero clocks inside the corresponding zero cylinders and found
their first exact witnesses after enumeration indices \(5,9,15\).

### 3. A genuinely non-sofic action

The new native point-mass programs are

\[
\delta_y(x)
=
\begin{cases}
1,&x=y,\\
0,&x\neq y.
\end{cases}
\]

They are bounded, certified total, and computable because equality in the exact
implemented group is decidable.

Translation gives

\[
\alpha_g(\delta_e)(x)
=\delta_e(g^{-1}x)
=\delta_g(x).
\]

If \(\alpha_g\) were the identity automorphism, then
\(\delta_g=\delta_e\), which forces \(g=e\). Hence

\[
g\longmapsto\alpha_g
\]

is injective.

The orbit

\[
\mathcal O_\delta=\{\delta_g:g\in G\}
\]

is consequently equivariantly isomorphic to the regular \(G\)-set \(G\). Its
stabilizer at \(\delta_e\) is trivial.

This closes the earlier theorem gap. In the countable-set-action definition of
[Gao, Kunnawalkam Elayavalli, and
Patchell](https://doi.org/10.1007/s40687-025-00526-6), Theorem 2.12 implies that
if the regular action \(G\curvearrowright G=G/\{e\}\) were sofic, then \(G\)
itself would be sofic. Proposition 2.15 says that a sofic action restricts to a
sofic action on each orbit. Therefore:

\[
G\curvearrowright\mathcal B_{\mathrm{cert}}(G,\mathbb Z)
\text{ sofic}
\Longrightarrow
G\curvearrowright\mathcal O_\delta\text{ sofic}
\Longrightarrow
G\text{ sofic},
\]

contradicting the exact non-soficity theorem for \(G\). Hence the full action on
the semantic program set is non-sofic under that published definition.

The conclusion is deliberately precise. We have not yet proved that the full
transformation groupoid is non-sofic under every existing definition of sofic
groupoids. In particular, [Cordeiro's sofic-groupoid
definition](https://arxiv.org/abs/1708.08023) is for
probability-measure-preserving groupoids, while this construction deliberately
chooses no probability measure. We have proved non-soficity of the underlying
countable-set action, which is already stronger than merely embedding a
non-sofic subgroup into its automorphism group.

## Continuation geometry

Fix a computable enumeration

\[
x_0,x_1,x_2,\ldots
\]

of exact group continuations. For extensionally distinct programs, define

\[
N(p,q)=\min\{n:p(x_n)\neq q(x_n)\}
\]

and

\[
d(p,q)=2^{-(N(p,q)+1)}.
\]

Set \(d(p,q)=0\) when \(p\sim q\).

This is the standard first-difference ultrametric on continuation-value
sequences. Its open balls are precisely finite continuation cylinders. The
particular numerical metric depends on enumeration, but the product-cylinder
topology does not.

A semantic state is therefore not required to have one finite coordinate
description. It may be given by the compatible family

\[
U_{\{x_0\}}(p)
\supseteq
U_{\{x_0,x_1\}}(p)
\supseteq\cdots.
\]

Each finite stage is exact. No finite stage need isolate the point.

This formalizes the red/green reflection. A visible label is a coarse quotient
of the continuation space. An intermediate state can exist as a complete
continuation pattern even though no current finite observable isolates it. A
later continuation reveals a distinction that was already semantically present.

## Observer-relative holonomy

Let the starting native state be \(\delta_e\). Compare two transport paths:

\[
\gamma_0=e,
\qquad
\gamma_1=g\neq e.
\]

Their exact endpoints are

\[
\alpha_e(\delta_e)=\delta_e,
\qquad
\alpha_g(\delta_e)=\delta_g.
\]

Choose a coarse finite observer whose continuation set omits \(e\) and \(g\).
Both point masses return zero on every visible continuation, so

\[
\pi_F(\delta_e)=\pi_F(\delta_g).
\]

The transported path \(g\) therefore appears to be a closed loop in the coarse
quotient even though its exact endpoints differ. Adding continuation \(e\)
opens the loop immediately:

\[
\delta_e(e)=1,\qquad\delta_g(e)=0.
\]

The runtime executed exactly this construction with eight coarse probes and one
refining continuation. It retained the exact nonidentity group hash as the
holonomy certificate.

This is **observer-relative holonomy**: a nontrivial exact transport becomes a
loop only because the observer identifies its endpoints. It is not being
claimed as intrinsic isotropy of the unquotiented transformation groupoid.

## Why this is beyond probability

Probability assigns a scalar valuation to observables. It does not define:

- which finite continuations exist;
- which histories compose;
- when two complete continuation patterns are extensionally equal;
- how semantic content transports along an exact path;
- which coarse observers turn transports into loops; or
- whether the transport group admits faithful finite models.

Those belong to topology, algebra, and path geometry. A probability state
\(\omega\) can query the path algebra afterward:

\[
a\longmapsto\omega(a).
\]

Thus the conceptual order is

\[
\text{continuation topology}
\rightarrow
\text{transport groupoid}
\rightarrow
\text{path algebra}
\rightarrow
\text{optional probability state}.
\]

The earlier formulation as a “self-extending noncommutative probability space”
was therefore too narrow. The deeper object is a self-extending noncommutative
path space; probability is one possible external shadow.

## The architectural object: an obstruction-generated semantic atlas

The next step is not a larger fixed feature vector. It is a learner whose
observable topology grows when a target-conflicting fiber is discovered.

At stage \(n\), let \(P_n\subset G\) be the finite continuation set currently
visible to the learner. It induces the quotient

\[
\pi_{P_n}(p)=(p(x))_{x\in P_n}
\]

and a finite observational topology \(\tau_n\). If two states in the same fiber
of \(\pi_{P_n}\) demand incompatible predictions, the obstruction engine finds
an exact continuation witness and attaches a chart. Thus

\[
\tau_0\subsetneq\tau_1\subsetneq\tau_2\subsetneq\cdots
\]

only as demanded by the task. Learning changes not just parameters inside a
fixed representation, but the family of distinctions the representation can
express.

For a reference path \(t\), define the chart-normalized coordinate

\[
\Phi_{t,x}(p)
=\bigl(\alpha_{t^{-1}}p\bigr)(x)
=p(tx).
\]

If a common continuation \(u\) acts on both the state and its reference path,
then

\[
\Phi_{ut,x}(\alpha_u p)
=\Phi_{t,x}(p).
\]

This identity is the executable core of exact compositional memory. The chart
does not memorize every absolute witness independently. It pulls path-relative
differences back to a shared coordinate, so one learned readout can transfer
across exact contexts.

The resulting proposed architecture is an **Obstruction-Generated Semantic
Atlas**:

1. an exact intensional carrier stores program and transport path;
2. a finite neural readout operates on the current charts;
3. a collision monitor finds target-conflicting observational fibers;
4. an exact obstruction certificate supplies a separating continuation;
5. a chart attachment transports that witness to a reusable local coordinate;
6. transition maps preserve the coordinate under further composition.

Externally, every finite consistent task can receive enough charts for an
epsilon-accurate finite readout. Internally, the full transport action has no
sofic global finite model. This is the precise executable version of an
**externally universal, internally non-sofic approximator**.

## Holonomy-chart learning ablation

`holonomy-chart-ablation.mjs` tests the first architecture-level consequence.
It constructs four distinct exact base paths. In every base chart it compares a
reference path \(t\) with an alternate path \(tg\), where \(g\neq e\). The
same left continuation \(u\) is then applied to both. Exact composition gives

\[
(ut)^{-1}(utg)=g,
\]

so the residual path memory survives the common continuation.

Eight coarse endpoint probes omit all endpoint supports. All eight examples
therefore fall into one visible fiber even though their target Bernoulli
parameters alternate between \(0.1\) and \(0.9\). The endpoint-only learner has:

- an exact minimax total-variation error floor of \(0.4\);
- conditional information gap \(0.3680642071684971\) nats; and
- trained predictions equal to \(0.5\) for every example.

Four absolute continuation witnesses would separate the four base charts. The
chart pullback instead maps all four to one identity coordinate. With that one
coordinate, the same two-parameter logistic readout predicts all eight targets
with maximum error \(2.56\times10^{-15}\), and the conditional information gap
falls to zero.

This is a finite constructive result, not evidence that non-soficity alone
improves general machine learning. What it establishes is narrower and useful:
path-relative exact memory can be made reusable by chart transport, while any
learner confined to the specified endpoint quotient is information-theoretically
incapable of the task.

## Prior-art boundary

The ingredients each have neighbors in existing work:

- [Growing Neural Gas](https://papers.nips.cc/paper/893-a-growing-neural-gas-network-learns-topologies)
  incrementally adds units and edges to represent the topology of vector data.
- [Active feature acquisition](https://proceedings.mlr.press/v267/norcliffe25a.html)
  sequentially selects informative measurements.
- [Atlas-based representation learning](https://arxiv.org/abs/2106.07062)
  uses learned charts as a target geometry.
- [Neural sheaf diffusion](https://arxiv.org/abs/2202.04579) learns local linear
  restriction maps over a graph.

The present construction is not identical to any of those: its charts are
synthesized by exact semantic collision certificates; its transition maps come
from an exact non-sofic action; its topology is a growing family of observable
distinctions rather than an inferred geometry on a fixed vector cloud; and its
finite readout is only task-locally universal. A targeted search found no prior
work combining those four clauses. That is a novelty hypothesis, not a claim of
exhaustive priority; a formal literature review and expert review remain needed.

## What the result establishes—and does not

### Established

- Every finite native continuation used by the construction is computable.
- The cylinder topology has a constructively non-isolated zero state.
- Point masses make the exact translation action faithful.
- The point-mass orbit is the regular \(G\)-set.
- The full action on the countable semantic-program set is non-sofic under the
  Gao--Kunnawalkam Elayavalli--Patchell definition.
- A finite observer can identify exact path endpoints and thereby create an
  observer-relative holonomy loop.
- A deeper exact continuation can open that loop.
- A chart-normalized holonomy coordinate is invariant under common left
  continuation and defeats a proved endpoint-only prediction floor in the
  finite ablation.

### Not established

- That all non-finitely-isolated continuation spaces have non-sofic transport.
  They do not; these are independent properties combined here.
- That the entire transformation groupoid is non-sofic under a selected
  probability-measure-preserving or topological groupoid-soficity definition.
  No measure has yet been selected.
- That the computable program subspace or its completion is uncountable.
  The native program set is countable; its ambient product space and possible
  completion are separate questions.
- That the finite holonomy ablation yields a broad empirical machine-learning
  advantage, or that its advantage is caused by non-soficity rather than exact
  path memory and adaptive observability.

## Next theorem and experiment

The finite holonomy learner now passes. The next nontrivial target is **atlas
compression versus raw-probe growth**: generate many base charts and residual
words, then prove that transported coordinates achieve sublinear chart growth
where a specified global probe class needs one new absolute witness per chart.

`atlas-probe-scaling.mjs` proves the first restricted form. It chooses \(n\)
pairs

\[
(\delta_{t_i},\delta_{t_i g})
\]

whose two-point supports are mutually disjoint. An absolute point evaluation
can distinguish pair \(i\) only at \(t_i\) or \(t_i g\), and therefore one such
probe can serve at most one pair. Exactly \(n\) probes are necessary and
sufficient. Pulling each pair back through its own reference chart sends every
pair to \((\delta_e,\delta_g)\), so the one coordinate at \(e\) separates all
of them. The executable audit verifies scales \(2,4,8,16,24\):

\[
C_{\mathrm{absolute\ point}}(n)=\Theta(n),
\qquad
C_{\mathrm{transported\ chart}}(n)=\Theta(1).
\]

The readout is then trained on only four base charts, frozen, and evaluated on
twenty unseen exact base charts. Because chart normalization exposes the same
residual coordinate in every chart, the two-parameter logistic readout retains
maximum held-out error below \(10^{-10}\) without changing its weights. This is
transfer across exact paths supplied by the algebraic chart rule, not evidence
that the neural readout discovered the rule unaided.

This lower bound applies to absolute point-evaluation features, not arbitrary
global program features designed with complete task knowledge. The next gap is
to define a natural bounded-cost global feature class and prove a separation
against it, followed by an out-of-sample experiment where charts learned on
some paths transfer to unseen base paths.

## Conditional semantic point-query update

A conditional version of that gap is now proved under an explicit semantic
point-evaluation cost model. A program may query the semantic state adaptively
at any group continuations, combine the answers with arbitrary nonlinear
computation, and emit any value. If its total point-query budget is (Q), its
all-zero transcript can touch at most (Q) of the mutually disjoint residual
pairs. Therefore every context-blind observer in this class separating all
(n) pairs needs

\[
Q\ge n.
\]

A bank of (m) features with at most (b) semantic evaluations each satisfies

\[
mb\ge n.
\]

The context-addressed chart still uses one evaluation and one shared coordinate
when the live reference path is supplied. The theorem includes a randomized
error lower bound and explicitly counts the reference-address cost; it does not
misstate coordinate compression as constant total storage. See
[`bounded-feature-separation.md`](bounded-feature-separation.md) and
`bounded-feature-separation.mjs`.

Adversarial controls falsify the broader coordinate-dimension and total-memory
interpretations. A one-scalar global sum solves the task using (n) point
queries; a distribution sample solves the point-mass task under a stronger
interface; and any ordinary baseline given the same reference context matches
the atlas in one query. Thus the remaining gap is twofold: extend the lower
bound to another defensible resource model, and couple a precisely defined
finite equivariant encoder to the non-sofic global obstruction.
