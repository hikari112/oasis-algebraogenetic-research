# Obstruction-Transport Genesis

## Status: exact finite square under a declared compiler

This experiment constructs two certificate-instantiated event orders whose
**order-forgetting** split/glue curricula agree while their declared linear
transports differ. The matrix theorem is exact, the implementation is
exhaustively checked on all small masks through six coordinates, and the
installed fixture has a rank-one loop defect.

The result is deliberately narrower than the original name suggested. The
certificate supplies the oriented masks. The experiment—not the certificate
theorem—declares that split masks act by lower shears and glue masks by upper
shears. That declaration creates the noncommutation. The one-use reducer has
only five reachable states. The finite dihedral group `D_8` is its eight-state
ambient closure, and one order bit distinguishes the two terminal histories.

The earned object is therefore a **certificate-instantiated finite transport
square**, not yet certificate-forced curvature, non-sofic closure, a Hodge
class, or an AI architecture advantage.

The executable companion is
[`obstruction-curvature-genesis.mjs`](obstruction-curvature-genesis.mjs).

## 1. What the preceding falsifiers taught us

The project began with the idea of an externally universal, internally
non-sofic approximator. Several attractive carriers failed under exact
controls:

- Cantor-cylinder density gives external representation universality, but not
  an ML efficiency theorem.
- The fixed comparison-defect interface is Moore-nonsofic, but its minimal
  state is only an integer counter; this is not group non-soficity.
- The comparison operation `q` can reduce bounded-propagation depth, but it
  transports all missing bits and therefore does not compress information.
- The Laurent germ preserves arrow history, but its group is the ordinary
  sofic binary lamplighter group and a sparse tape simulates it exactly.
- Bare XOR detects an error but loses whether sound repair requires a split or
  a glue.

The surviving insight is not a special coefficient field, probability law, or
memory device. It is a typed continuation problem: a process may need to grow
the diagram in which future questions are meaningful, while a terminal
observable algebra forgets some of the transport that formed it.

Before testing that idea, the controller's former side channel had to be
closed. The current oriented germ uses

\[
s=x(1-y),\qquad g=(1-x)y,
\]

where `s=1` means that an exactly distinct pair was collapsed and `g=1` means
that an exactly equal pair was separated. Challenge selection and synthesis
now factor through this germ rather than through a parallel raw-audit route.

## 2. Trust-boundary repairs made during the audit

The first square implementation passed its algebra tests but failed hostile
input tests. Those failures were treated as blocking defects.

The repaired controller now:

- freezes the certificate relation directory and binds each germ to its
  SHA-256 directory digest;
- records the critic anchor count and certificate relation index;
- requires every declared covered relation to contain its complete anchor
  block;
- compares any controller override with the complete canonical audit germ;
- requires an opaque one-use selection token before a routed violation can be
  compiled into an official challenge;
- verifies violation kind, polarity, severity, directory membership, exact
  word semantics, and proof step;
- rejects empty or incoherent split/glue atlas revisions; and
- rebuilds the next atlas on a fresh object, swapping controller state only
  after every validation succeeds.

Replay is also stable under caller alias mutation. The diagram snapshots exact
generator/inverse terms, certificate parameters, and probe-state values into a
private frozen record, then reconstructs fresh exact dependencies per
transaction. Its canonical committed-germ log is private and deeply frozen.
Mutating the source state maps, source oracle, exposed old atlas oracle, or a
fake public germ-log property cannot rewrite an earlier revision during replay.

The square no longer accepts caller-supplied matrices or a caller-defined
“canonical event” registry. Its transition consumes a typed germ, reroutes the
certificate challenge, derives the appropriate declared shear internally,
rebuilds the atlas, and then swaps the complete next state. Partial germs,
wrong directory digests, mutation of a previously committed source object, and
caller-supplied action fields are tested adversarially.

These are integrity checks inside the executable controller. The directory
digest is not a cryptographic signature from an external authority. A future
serialized protocol would still need an authenticated commitment to which
relations the upstream critic actually covered.

## 3. Two separately certified replay events

The square uses two real six-anchor fixtures:

- a split fixture that collapses an exact-nonidentity `j0` to the identity,
  producing six split cells; and
- a glue fixture that assigns `j0` a wrong-order permutation, producing four
  glue cells on an exact equality relator.

Each fixture independently routes through the oriented germ and produces a
valid atlas attachment. The events are then replayed in both orders.

This is **not** one demonstrated learner trajectory. The fixtures are two
different emulator worlds; the first attachment does not update a critic and
cause the second audit. Moreover, `covered=true` in the resulting atlas means
that a repair obligation was installed, not that the emulator was repaired.
The source critics still violate both installed tasks:

\[
L_{\mathrm{split}}=1,
\qquad
L_{\mathrm{glue}}=\frac23.
\]

A causal learning result requires

\[
\mathrm{audit}_0\to\mathrm{repair}_1\to\mathrm{critic}_1
\to\mathrm{audit}_1\to\mathrm{repair}_2,
\]

followed by an independently generated future task.

## 4. Declared dual-shear transport

Let `C` be the finite set of semantic relation-anchor keys and work over
`F_2` in

\[
V=\mathbb F_2e_*\oplus\mathbb F_2[C].
\]

Write a vector as `(a,w)`. For the certificate-instantiated split and glue
masks `s,g in F_2[C]`, the experiment declares

\[
S_s(a,w)=(a,w+a s)
\]

and

\[
G_g(a,w)=(a+\langle g,w\rangle,w).
\]

Both maps are involutions. The first sends the shared continuation bit into
split coordinates; the second evaluates glue coordinates back into that bit.
This opposite triangular orientation is a designed transport convention. Mapping both masks
to lower shears makes the square commute, which confirms that polarity plus
the chosen compiler—not the certificate alone—creates the witness.

The shared bit `e_*` is an explicit interface, not hidden state. Every matched
control receives it.

## 5. Exact square theorem

The two path transports are

\[
P=G_gS_s,
\qquad
Q=S_sG_g.
\]

Their additive difference over `F_2` is

\[
\Omega(s,g)=P+Q.
\]

### Theorem 1: dual-shear square formula

For every finite pair of masks,

\[
\Omega(s,g)=
\begin{pmatrix}
\langle g,s\rangle&0\\
0&s g^{\mathsf T}
\end{pmatrix}.
\]

### Proof

In the declared decomposition of `V`,

\[
S_s=
\begin{pmatrix}1&0\\s&I\end{pmatrix},
\qquad
G_g=
\begin{pmatrix}1&g^{\mathsf T}\\0&I\end{pmatrix}.
\]

Multiplying both orders and adding over `F_2` gives the displayed block
matrix. `QED`

For the installed fixture, `|s|=6`, `|g|=4`, and the supports are disjoint.
Therefore `<g,s>=0`, the outer product has rank one, and it has exactly
`6*4=24` nonzero matrix entries. Those entries are one rank-one degree of
freedom, not 24 information bits. All five fixture facts are asserted
explicitly, so future fixture changes cannot silently preserve a stale report.

The executable also checks the general identity, rank formula, and support
formula for all `5,460` mask pairs on one through six coordinates.

## 6. Relative holonomy and the finite-group collapse

Define

\[
N(a,w)=(0,a s),
\qquad
M(a,w)=(\langle g,w\rangle,0).
\]

For the disjoint installed supports,

\[
N^2=M^2=MN=0,
\qquad
NM=K,
\]

where

\[
K(a,w)=(0,\langle g,w\rangle s),
\qquad K^2=0.
\]

Thus

\[
P=I+M+N,
\qquad
Q=I+M+N+K.
\]

The relative loop transport is

\[
H=Q^{-1}P=P^2=I+K.
\]

It is nonidentity and `rank(H-I)=1`. A source/endpoint frame change conjugates
`H`, so nontriviality and rank survive a change of vector-space basis.

But this does not produce an exotic carrier. `S^2=G^2=I`, the product `GS`
has order four, and the generated group has exactly eight elements:

\[
\langle S,G\rangle\cong D_8.
\]

The executable enumerates all eight matrices. The actual one-use process can
reach only `I`, `S`, `G`, `GS`, and `SG`; thus it is a five-state reducer
embedded in `D_8`, and three bits are merely the minimum integer width for its
five states. The other three group elements arise only by allowing repeated
generator use beyond this fixture's event protocol.

## 7. What the endpoint comparison really says

Applying both challenges in either order gives the same sorted pair of sets

\[
(\mathsf{Sep},\mathsf{Glue}).
\]

That equality holds only after deliberately forgetting revision order. The
full atlas snapshots already differ because they retain their ordered revision
logs. Accordingly, the theorem is:

> The order-forgetting curriculum quotient is insufficient for the declared
> transport-coordinate query.

It is not a theorem that every natural endpoint representation must fail.
Endpoint plus one order bit succeeds exactly. More strongly, the ordinary full
atlas already stores revision order, so it answers this displayed query with
zero additional persistent bits. The one-bit comparison applies only after we
deliberately quotient that order away.

After both replay diagrams exist, the experiment chooses one real glue support
coordinate as input and one real split support coordinate as output. The
declared transports return `0` for split-then-glue and `1` for
glue-then-split. This is an auxiliary matrix-coordinate query designed from
the known supports. It is not a held-out certificate task, an atlas loss, or a
learned prediction.

A separately implemented closed-form control—not matrix multiplication—matches
all `4,802` coordinate queries on the 49 basis inputs. It uses the same declared
masks and order bit; it is an implementation control, not an independent
compiler. For the displayed query the formula reduces to whether glue was the
first accepted event, which the full atlas log also reveals directly.

## 8. Naturality boundary

Simultaneously permuting the declared vector-space basis conjugates `S`, `G`,
`Omega`, and `H`. The executable checks a complete reversal and the general
identity follows algebraically.

This is basis covariance, not yet full semantic naturality. The test does not
simultaneously relabel and reconstruct:

- the certificate relation directory and proof types;
- the critic and its audit;
- the atlas attachments;
- the future query language; or
- embeddings between refinement stages.

A genuine genesis functor must make that larger diagram commute.

## 9. Exact controls

The finite square loses against every sufficiently informed ordinary program:

- an ordered event tape reproduces both paths;
- a three-bit state represents the five reachable reducer states (and also all
  eight elements of the ambient `D_8` closure);
- a one-bit terminal state distinguishes the two both-committed histories;
- the full atlas log needs no extra bit for the displayed query because its
  first revision already identifies the order;
- a direct global formula answers every tested coordinate query;
- an order-blind bag fails only because it intentionally discards the needed
  order bit; and
- replacing the glue shear by another lower shear makes the square flat.

The square therefore establishes path-sensitive auxiliary transport under a
declared law. It establishes no memory, compression, runtime, sample,
parameter, prediction, or optimization advantage.

## 10. What remains conceptually valuable

The audit does not erase the larger intuition; it tells us where the real
mathematics cannot be faked.

A completed observable algebra can be a fossil of a process when it forgets
how future questions are transported. Probability can later value observables
available at a stage, but probability does not generate their types or the
rules by which new questions become admissible. The candidate carrier is a
continuation geometry:

\[
\text{typed obstruction}
\longrightarrow
\text{validated attachment}
\longrightarrow
\text{transported future availability}.
\]

The finite square shows how such data can be represented. It does not show
that the data are forced, unbounded, or non-sofic. In fact, the 49-dimensional
module is allocated from the union of both future germs before either history
runs. Every tested query is consequently callable from the start. This is a
fixed-space transducer, not yet growth of question availability or topology.

The “continuous irrational algebra” intuition can now be stated as a research
hypothesis without invoking irrational coefficients: seek a compatible
refinement limit of executable typed diagrams whose local continuations are
computable but whose global future-equivalence relation has no finite faithful
closure. The finite `D_8` square is only a local toy model of that hypothesis.

## 11. Provisional future-commit equivalence

The earlier proposal

\[
h\equiv_{\mathrm{fc}}h'
\]

when every common continuation yields naturally equivalent validated diagrams
is not yet a definition. It has at least four defects:

- histories with no common continuation could become vacuously equivalent;
- independently chosen equivalences need not be coherent across continuation;
- admitting every attachment and query can collapse the notion to raw diagram
  equality; and
- growing alphabets, coordinates, or query addresses can create trivial
  residual growth.

A rigorous successor needs a typed transition system or fibration, an explicit
availability observable, a fixed query language, coherent gauge maps, and a
proof that the resulting relation is a right congruence or bisimulation.

## 12. The next nontrivial target

Merely taking direct sums of this square would produce many states but no new
theorem. The next target must satisfy all of the following:

1. **Natural transport law.** Derive split and glue transport from a universal
   property or explicit semantic repair law; do not choose matrices after
   seeing the desired commutator.
2. **One causal critic.** Demonstrate an actual
   `audit -> repair -> updated critic -> audit` trajectory.
3. **Held-out continuation.** Let a third certificate or fixed query language
   generate the separating future task after the histories are formed.
4. **Fixed interface.** Hold the event alphabet, external query interface, and
   address-cost model fixed as the refinement radius grows. Do not preallocate
   coordinates from future-specific germs.
5. **Gauge/refinement persistence.** Prove that relative holonomy survives the
   permitted changes of frame and embeddings, rather than only one basis
   permutation.
6. **Bounded-future residual growth.** At action radius `L`, prove at least
   `2^(cL)` histories are separated by suffixes of bounded declared cost.
7. **Equal-information controls.** Give tapes, sparse maps, finite programs,
   and global features the identical events, addresses, and query language.
8. **Honest total cost.** Charge certificate length, germ-mask bits, action
   payload, continuation length, and query-address length; an unbounded germ
   cannot count as one fixed-alphabet action.
9. **Semantic gauge quotient.** Specify the semantics-preserving gauge and
   prove the witness survives every allowed gauge/refinement, not merely an
   identity gauge or a convenient block embedding.
10. **Availability observable.** Exhibit a query that is genuinely unavailable
    before refinement and becomes callable afterward; changing an answer inside
    a preallocated module is insufficient.
11. **Natural-compiler load bearing.** Exclude generic free-group residual
    growth by proving that the large residual family is forced by the repair
    certificate semantics.

Even that would establish a fixed-interface Moore/residual theorem, not group
non-soficity. The latter still needs the separate effective universal
`(F_0, epsilon_0)` obstruction and a reduction showing that every proposed
finite approximately two-sided transport closure would yield the forbidden
finite approximation.

## 13. Hodge and complexity boundary

The word “holonomy” is literal for the finite loop. “Curvature” remains
provisional because no refinement complex, cochain theory, coboundary,
gauge-equivalence class, or persistence theorem has been built. A Hodge claim
would additionally require an inner product, adjoint, Laplacian, and harmonic
representative.

Nothing here implies `P=NP`, bypasses the algebrization barrier, changes Galois
theory, or proves a new universal approximator. The concrete foundational
question that remains is:

> Can computability live in locally executable continuation while every fixed
> finite semantic closure loses some bounded-cost future distinction?

The audit has made that question harder to satisfy and much harder to fake.
