# OASIS non-sofic research

Public working archive for the OASIS non-sofic universal-estimator and
algebraogenetic semantic-atlas research program.

This is an exploratory research repository, not a claim to have resolved any
named open problem.  Each theorem-facing note is expected to separate exact
finite results, conditional constructions, declared semantic choices, and open
gaps.

## Public audit

- Anyone may read, clone, and fork the repository.
- Only explicitly authorized collaborators can push to this repository.
- Changes to `main` must go through a pull request; force pushes and branch
  deletion are disabled, and unresolved review conversations block merging.
- External audits are welcome as issues or pull requests from forks.  The most
  useful reports identify the exact statement, assumption, proof step, or
  executable certificate being challenged and provide a minimal falsifier when
  possible.
- Do not submit credentials, private datasets, or machine-local configuration.

## Repository map

- `outputs/oasis-nonsofic-engine/` contains the theorem-facing implementation,
  executable certificates, architecture notes, and verified experiments.
- `work/` contains source papers, numerical solver products, exact quotient
  exports, and intermediate research evidence.

The two radius-two quotient exports larger than GitHub's normal per-file limit
are stored with Git LFS. Clone with Git LFS enabled to retrieve their full
contents.

Start with `outputs/oasis-nonsofic-engine/README.md`.
