# OASIS non-sofic research

Private working archive for the OASIS non-sofic universal-estimator and
algebraogenetic semantic-atlas research program.

## Repository map

- `outputs/oasis-nonsofic-engine/` contains the theorem-facing implementation,
  executable certificates, architecture notes, and verified experiments.
- `work/` contains source papers, numerical solver products, exact quotient
  exports, and intermediate research evidence.

The two radius-two quotient exports larger than GitHub's normal per-file limit
are stored with Git LFS. Clone with Git LFS enabled to retrieve their full
contents.

Start with `outputs/oasis-nonsofic-engine/README.md`.
